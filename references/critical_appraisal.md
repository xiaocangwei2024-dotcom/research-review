# 批判性评估

## 对齐后再解释分歧

将双方证据先放到同一比较框架，逐项核对共享假设、对象、对照、测量、效应方向、条件和时间。只把相同或可比较问题上的不兼容结论标为冲突。检查若干论文是否以不同指标评价同一术语。涉及交叉学科时，注明相同表述是否对应相同构念。〔约定依据：[比较与批判性评估阶段](../SKILL.md#工作流程)〕

| 冲突双方与证据编号 | 核对维度 | 归因与可检验方式 |
| --- | --- | --- |
| 并置各自结论、对象及读取层级 | 方法、对象、语境、时间 | 写明能够支持解释的比较或复现。孤立差异可作为可能归因。材料不足时标记无法归因。 |

追踪共享假设的来源、后续使用和修正。区分文献直接引用、对同一结果的复现以及综述者对独立研究的并列。记录哪条证据能支持每种关系。〔约定依据：[比较与批判性评估阶段](../SKILL.md#工作流程)〕

## 三类不一致和四类不足

| 检查 | 要问的问题 |
| --- | --- |
| 结论不一致 | 对同一命题，结果方向、大小或适用界限是否有差别？ |
| 视角不一致 | 微观、中观、宏观或时间动态是否覆盖不均？分析层次能否对话？ |
| 方法不一致 | 不同识别策略、测量工具或数据窗口所支持的结论有何差别？ |
| 视角盲区 | 哪些变量、机制或层次尚未得到检验？ |
| 方法局限 | 采样、设计、构念信效度或对照能解释到哪里？ |
| 样本偏差 | 哪些群体、地区、语言或典型情境在现有样本中覆盖较少？ |
| 理论滞后 | 哪些新现象超出当前理论在纳入证据中验证过的边界？ |

逐项报告“有证据”“纳入证据未发现”或“资料不足”。把每条成立的空白写成“证据编号与边界 → 空白 → 可检验问题”。至少关联一篇已核验文献，条件允许时关联两篇及以上，指明可观察变量、结果或可比较条件。用“在本次纳入材料中”限定没有观察到的证据。〔约定依据：[比较与批判性评估阶段](../SKILL.md#工作流程)〕

## 证据强度与平衡

提取研究对象和样本、设计与识别、测量、结果精度、可复现性以及跨情境适用性。用“强 / 中 / 初步 / 无法评估”加短理由表达对该命题的支持程度。读到的全文与论文发表状态都应单独记录。只读到元数据时不评估结论强度。预印本、方法欠充分或单样本结果须明确边界，保留有价值的反向证据。观察性关联、模型评分及理论推演分别按各自证据类型表述。〔约定依据：[比较与批判性评估阶段](../SKILL.md#工作流程)〕
